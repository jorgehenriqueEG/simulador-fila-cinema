# Simulador Fila Cinema
## Descrição do Problema
Simula o tempo de espera em um cinema com dois tipos de fila: infantil (com acompanhante) e adulto (sozinho).
## Requisitos
- Calcular tempo total de espera para cada cliente.
- Filas infantis têm prioridade quando a fila adulta está vazia.
## Exemplo de Uso
Entrada: [{"nome": "Joao", "tipo": "adulto"}, {"nome": "Maria", "tipo": "infantil"}]
Saída: {"Joao": 30, "Maria": 60}
